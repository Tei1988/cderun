# Task Management Agent Skill

このディレクトリには、AIエージェントおよび開発者が `todo.md` に定義されたバックログタスクを効率的に追跡・管理するための自動化スクリプトが用意されています。
このツールを使用することで、タスクの新規追加、ステータス更新、および冗長になった手順の削除が自動化され、再現性の高い作業環境が整えられます。

## 特徴と機能

- **list**: `todo.md` 内の全タスクとそのステータス（例：`DONE` や `-`）を一覧表示します。
- **show <task_id>**: 特定のタスクの詳細（タイトル、現在のステータス、およびファイル下部にある詳細手順・解説セクション）を抽出してターミナル上に表示します。
- **done <task_id>**: 特定のタスクのステータスを自動的に `DONE` に更新し、ファイル下部にある該当タスクの詳細な手順セクション（`## T<ID>: ...`）を安全に自動削除します。
- **add <task_id> <title> <type> <priority> <size> [--spec-change <spec_change>] [<details>]**: 新しいタスクをサマリーテーブルに追加し、指定した詳細手順をファイル下部に自動的に追記します。
- **delete-details <task_id>**: タスクの完了ステータスはそのまま（または変更せず）に、該当タスクの詳細手順セクション（`## T<ID>: ...`）だけを安全に削除します。

## 使用方法

スクリプトは `python3` で動作します。

### 1. タスクの一覧表示

```bash
python3 .agent/manage_task.py list
```

### 2. タスク詳細の表示

```bash
python3 .agent/manage_task.py show T58
```

### 3. タスクの完了（ステータス更新と詳細セクションの削除）

```bash
python3 .agent/manage_task.py done T58
```

### 4. タスクの新規追加（詳細手順付き）

```bash
python3 .agent/manage_task.py add T99 "新しい機能の追加" "機能" "中" "小" "これは新しい機能の詳しい実装要件です。"
```

### 5. 詳細手順セクションのみの削除

```bash
python3 .agent/manage_task.py delete-details T58
```

## 再現性向上のための設計

このツールは、正規表現ベースでMarkdownテーブルおよびMarkdown見出しを安全にパースするため、セクション間にある他のテキストを破壊することなく正確に変更を適用します。これにより、誰が実行しても同じ品質でタスクの追加やクリーンアップが行えます。
